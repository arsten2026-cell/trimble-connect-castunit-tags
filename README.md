# Cast unit tags (Arsten), Trimble Connect 3D-viewer extension

Lists the Tekla cast units in the loaded IFC models (export with Cast-in-place = "CIP cast units or parts"), with
concrete volume and rebar weight. Tags each cast unit with a leader label, selects, focuses and colours them, and
shows each cast unit's rebar list (Pos | Ø | pcs | kg) from Tekla's own rebar objects.

Install: Trimble Connect project → Settings → Apps & Capabilities → + Add Custom →
`https://arsten2026-cell.github.io/trimble-connect-castunit-tags/manifest.json`. Then open a model in 3D and pick
"Cast unit tags" in the side panel.

Static files only, no data leaves the browser.
